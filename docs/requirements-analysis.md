# 智能客服话术库系统 — 需求分析文档

> 版本: v1.0  
> 更新日期: 2026-07-15  
> 项目代号: smart-cs-assist

---

## 一、项目背景与目标

### 1.1 背景

客服人员每天需要处理大量来自微信等渠道的客户售后反馈，包括产品质量问题、服务投诉等。当前痛点：

- 客服回复质量参差不齐，依赖个人经验
- 缺乏统一、可维护的标准话术库
- 无法快速定位客户问题类型并匹配合适回复
- 优质回复无法沉淀复用

### 1.2 目标

构建一套**智能客服话术辅助系统**，帮助客服人员：

1. 快速识别客户问题类型
2. 自动匹配或生成 3~5 条专业回复供选择
3. 持续沉淀优质回复，不断丰富话术库
4. 支持 Excel 批量导入历史话术

---

## 二、用户角色

| 角色 | 说明 |
|------|------|
| 客服人员 | 日常使用系统处理客户反馈，选择/使用回复话术 |
| 话术库管理员 | 维护话术库内容（增删改查），导入导出数据 |

## 三、功能模块详述

### 模块 A：智能分析主页（客服工作台）

#### A1. 客户问题输入

- **输入框**：客服粘贴/输入客户在微信中反馈的原始问题文本
- **字数统计**：显示当前输入字数
- **清空按钮**：一键清空输入

#### A2. 问题分类快速定位

- **分类按钮组**：预设常见售后问题分类，以按钮形式展示
  - 示例分类：产品质量问题、物流配送、退款退货、使用方法咨询、服务态度投诉、售后保修、其他
- **两级分类**：大类 → 小类（如：产品质量 → 外观瑕疵 / 功能故障 / 配件缺失）
- **点击行为**：点击分类按钮后，自动筛选话术库中该分类下的回复
- **快捷搜索**：支持在分类下输入关键词进一步缩小范围

#### A3. 智能分析模式切换

- **开关控件**：顶部显眼位置的 Switch 开关
  - 关闭（本地模式）：使用本地算法匹配话术库
  - 开启（AI 模式）：调用大模型生成回复

#### A4. 本地匹配模式（AI 关闭时）

- **算法流程**：
  1. 对客户问题进行中文分词 + 关键词提取
  2. 结合用户选择的分类进行加权
  3. 在话术库中进行相似度匹配（TF-IDF + 余弦相似度 / Jieba 分词匹配）
  4. 按匹配度降序返回 Top 3~5 条话术
- **展示方式**：卡片列表，每条显示：
  - 匹配度百分比
  - 话术内容预览
  - 所属分类标签
  - "选择使用"按钮

#### A5. AI 智能模式（AI 开启时）

- **提示词构造**：将客户问题 + 所选分类 + 系统预设 Prompt 拼接发送给大模型
- **系统 Prompt 设计要点**：
  - 角色设定：你是一名专业的售后客服专家
  - 输出要求：生成 3~5 条不同角度/语气的回复
  - 格式要求：JSON 数组，每条包含回复内容和适用场景
  - 语气要求：专业、礼貌、有同理心
  - 约束：不承诺无法兑现的事项，不透露内部信息
- **大模型接口**：支持 OpenAI 兼容 API（可配置 Base URL + API Key）
- **展示方式**：与本地模式类似的卡片列表，额外标注「AI 生成」标签
- **容错处理**：API 超时/失败时回退到本地匹配模式

#### A6. 回复选择与反馈闭环

- **选择操作**：客服点击某条回复的"使用"按钮
- **复制功能**：一键复制回复内容到剪贴板
- **反馈入库**：用户选择的回复自动标记为「已验证」
  - 若来自 AI 生成：将该回复作为新话术写入话术库（需填写分类）
  - 若来自话术库匹配：增加该话术的"使用次数"计数
- **评分反馈**：可选的对回复进行 👍/👎 评分

### 模块 B：话术库数据管理

#### B1. 话术列表页

- **表格展示**：分页表格，列包含：
  - ID、话术内容（截断显示）、所属分类、标签/关键词、使用次数、创建时间、更新时间、状态
- **搜索过滤**：
  - 按分类筛选（下拉框）
  - 按关键词搜索（模糊匹配话术内容）
  - 按状态筛选（启用/禁用）
- **排序**：按使用次数、创建时间排序

#### B2. 新增话术

- **表单字段**：
  - 话术内容（必填，TextArea，支持多行）
  - 所属一级分类（必填，下拉选择）
  - 所属二级分类（选填，下拉选择，联动一级分类）
  - 标签/关键词（选填，Tag 输入，用于匹配算法）
  - 适用场景说明（选填）
- **批量添加**：支持一次输入多条（用分隔符分开）

#### B3. 编辑话术

- 点击编辑进入编辑模式，表单预填充原有数据
- 保存后更新 `updated_at` 时间戳

#### B4. 删除话术

- 单个删除（二次确认弹窗）
- 批量删除（勾选 + 批量操作）

#### B5. Excel 导入

- **上传按钮**：点击触发文件选择
- **支持格式**：`.xlsx`、`.xls`、`.csv`
- **模板下载**：提供标准导入模板下载
- **列映射**：上传后预览解析结果，支持手动映射列
- **导入策略**：
  - 追加模式：不检查重复，直接新增
  - 去重模式：按话术内容去重后新增
- **结果反馈**：显示成功/失败条数，失败原因

#### B6. Excel 导出

- 导出当前筛选结果为 Excel
- 导出全部话术为 Excel（备份功能）

---

### 模块 C：分类管理

#### C1. 分类列表

- 树形结构展示一级/二级分类
- 每级显示下属话术数量

#### C2. 分类增删改

- 添加一级/二级分类
- 编辑分类名称
- 删除分类（如有关联话术则提示）

## 四、非功能性需求

### 4.1 性能

- 本地匹配响应时间 < 1 秒
- AI 模式响应时间 < 10 秒（含 API 调用）
- 话术库列表加载 < 500ms（1000 条数据内）

### 4.2 可用性

- 界面简洁，核心操作 2 步内完成
- 支持键盘快捷键（Enter 发送分析、Esc 清空等）
- 移动端响应式适配（客服可能在手机上使用）

### 4.3 安全性

- API Key 加密存储（后端环境变量或加密配置）
- 不将客户隐私数据明文记录日志
- 前端不暴露 API Key

### 4.4 可维护性

- 分类和话术支持导入导出，便于迁移
- 操作日志记录（谁在什么时间做了什么操作）
- 数据库定期备份提醒

## 五、数据模型概要

### 5.1 分类表 `categories`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| name | TEXT | 分类名称 |
| parent_id | INTEGER | 父分类ID（NULL=一级分类） |
| sort_order | INTEGER | 排序序号 |
| is_active | BOOLEAN | 是否启用 |

### 5.2 话术表 `scripts`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| content | TEXT | 话术内容 |
| category_id | INTEGER FK | 所属二级分类 |
| keywords | TEXT | 标签/关键词（逗号分隔） |
| usage_count | INTEGER | 使用次数 |
| rating_good | INTEGER | 好评数 |
| rating_bad | INTEGER | 差评数 |
| source | TEXT | 来源（manual/ai_import/excel_import） |
| is_active | BOOLEAN | 是否启用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 5.3 使用日志表 `usage_logs`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| script_id | INTEGER FK | 使用的话术ID |
| customer_query | TEXT | 客户原始问题 |
| category_id | INTEGER | 当时选择的分类 |
| mode | TEXT | local / ai |
| created_at | DATETIME | 使用时间 |

## 六、技术栈建议

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | React 18 + TypeScript | 组件化开发，类型安全 |
| 构建工具 | Vite 5 | 快速 HMR，开发体验好 |
| UI 组件库 | Ant Design 5 | 企业级组件，表格/表单/上传等开箱即用 |
| HTTP 客户端 | Axios | 请求拦截、错误处理 |
| 后端框架 | FastAPI (Python 3.10+) | 高性能异步，自动生成 API 文档 |
| ORM | SQLAlchemy 2.0 | 数据库操作 |
| 数据库 | SQLite | 轻量级，无需安装数据库服务 |
| 中文分词 | jieba | 关键词提取与匹配 |
| 相似度计算 | scikit-learn | TF-IDF 向量化 + 余弦相似度 |
| Excel 处理 | openpyxl / pandas | 读写 Excel 文件 |
| LLM 接口 | OpenAI Python SDK | 兼容多种大模型 API |

## 七、优先级划分

| 优先级 | 功能模块 | 说明 |
|--------|----------|------|
| P0 | 话术库 CRUD + Excel 导入 | 数据基础，最先实现 |
| P0 | 分类管理 | 话术分类的基础依赖 |
| P1 | 本地匹配模式 | 核心业务价值 |
| P1 | 问题分类快速定位按钮 | 提升效率的关键功能 |
| P2 | AI 智能模式 | 需要外部 API 依赖 |
| P2 | 反馈闭环（选择入库） | 持续优化话术库 |
| P3 | 使用统计与分析 | 数据驱动优化 |
| P3 | 移动端适配 | 拓展使用场景 |
